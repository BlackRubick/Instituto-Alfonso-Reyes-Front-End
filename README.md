# Instituto Superior de Estudios Profesionales Alfonso Reyes

Sitio web institucional desarrollado para representar digitalmente al Instituto Superior de Estudios Profesionales Alfonso Reyes mediante una experiencia moderna, clara y profesional. La plataforma centraliza información institucional, oferta educativa, preguntas frecuentes, recursos informativos, avisos legales y canales de contacto.

El objetivo del proyecto es facilitar el acceso a la información para aspirantes, estudiantes y visitantes, ofreciendo una navegación organizada, accesible y adaptable a distintos dispositivos.

## Acerca del proyecto

Este repositorio contiene una landing page institucional construida con React y Vite. El sitio está estructurado por secciones para presentar de forma clara la identidad del instituto, su propuesta académica y sus medios de comunicación oficiales.

## Características

- Diseño moderno y responsive
- Navegación por secciones
- Información institucional y académica
- Preguntas frecuentes
- Aviso de privacidad y términos legales
- Formulario y medios de contacto
- Optimización para rendimiento y accesibilidad

## Tecnologías utilizadas

- React
- Vite
- JavaScript
- CSS

## Objetivo

Brindar una presencia web profesional que permita comunicar la identidad y oferta educativa del instituto de manera clara, accesible y confiable.
